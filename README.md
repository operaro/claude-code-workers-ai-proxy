# Claude Code Workers AI Proxy

A serverless, edge-based adapter deployed on Cloudflare Workers. It intercepts Claude Code CLI requests (Anthropic `/v1/messages` format), authenticates them using your private API key, and streams back responses generated by open-source models on **Cloudflare Workers AI**.

Zero local background scripts or daemons required.

## 🔒 Configuration & Environment Secrets

### 1. Set Your Authentication Secret
After deploying or during configuration, set your private key secret:

```bash
npx wrangler secret put CUSTOM_PROXY_KEY
# Enter your desired secret key, e.g., "my-passcode-123"
```

### Is Claude Code Optimized for Tokens?

**Yes, but it is token-heavy by design.** 

Claude Code executes terminal commands, reads workspace files, analyzes project structures, and runs tests recursively. 
* **Large Context Windows:** On every execution loop, Claude Code sends back system prompts, current file content, shell command history, and tool output. A single task can quickly consume tens of thousands of tokens per conversation turn.
* **Compact Formatting:** Claude Code uses raw text block formats for tool execution rather than verbose JSON wrapping where possible, but context accumulators grow fast as you work across complex codebases.

### Will BYOK (Bring Your Own Key) via Cloudflare Workers AI Be Cost Effective?

**Extremely cost-effective.** Connecting Claude Code to Cloudflare Workers AI via BYOK is one of the cheapest setups available.

#### 1. Cloudflare Workers AI Pricing Advantage
* **Generous Free Tier:** Cloudflare Workers AI offers **10,000 free Neurons per day** (equivalent to roughly 100,000–300,000 free input/output tokens daily across smaller/medium models).
* **Low Paid Rates:** Once past the free tier, Workers AI charges ~$0.001 per 1,000 Neurons. Compared to Claude 3.7 Sonnet ($3.00/M input, $15.00/M output) or Claude 3.5 Haiku ($0.80/M input, $4.00/M output), routing to Llama 3.3 70B or DeepSeek R1 on Cloudflare drops your LLM compute costs by **80% to 95%**.

#### 2. Worker Execution Overhead
Cloudflare Workers run on CPU sub-milliseconds. Standard Worker execution costs are negligible:
* 100,000 free requests per day on the free Workers plan.
* Zero infrastructure setup costs—no running VPS, local servers, or Docker containers consuming battery and RAM.
